# 全カードリスト：人力回帰確認

自動テストだけでは確認しにくい、実際の見え方と操作の確認手順です。変更を本番へ出した後、変更箇所と関係する項目を確認します。

本番URL: `https://loveca-card-list.pages.dev/`

## 1. PCの基本表示

1. PCで本番を開く。
2. 上部のグループボタンを確認する。
3. `すべて`、μ's、Aqours、虹ヶ咲、Liella!、蓮ノ空、その他の順で表示されていることを見る。
4. カード件数が1817、内訳がメンバー1526・ライブ291と表示されることを見る。

正常なら、ボタン・見出し・カード一覧が重ならず、横スクロールなしで読めます。

## 2. その他カテゴリ

1. 上部の `その他` を押す。
2. その下に `すべて`、A-RISE、Saint Snow、Sunny Passion、その他ライブだけが1列で表示されることを見る。
3. それぞれを押して、該当するカードだけへ切り替わることを見る。

正常なら、旧来の「ライバルグループ」などの重複見出しは出ず、子分類を選んでも画面が空になりません。

## 3. Card Labo購入リンクとバージョン表示

1. `Aqours` を押す。
2. 「高海千歌 / PL!S-bp2-001」を探す。
3. カード表面に `公式カード情報` と `カードラボで購入（P）`、`カードラボで購入（R）` があることを見る。
4. `バージョンを見る（2種）` を押す。
5. PとRの各行に `公式カード情報` があることを見る。

正常なら、購入リンクはカード表面にだけあり、バージョン展開内には重複表示されません。リンクを開く場合は、新しいタブで該当サイトへ移動します。

## 4. 検索・候補・所持

1. 検索欄に `控え室 カード` と入力する。
2. `カード 控え室` に入れ替える。
3. 表示結果が同じになることを見る。
4. 任意のカードで `候補` を押し、表示が `候補中` に変わることを見る。
5. 所持数の `＋` を1回押し、所持表示が1枚になることを見る。
6. `候補のみ表示` と `所持のみ` を必要に応じて使い、該当カードが絞り込まれることを見る。

正常なら、候補と所持は独立しており、検索・絞り込み中でも操作できます。確認後は候補を戻し、所持数を0へ戻します。

## 5. デッキ

1. 任意のカードで `デッキに追加` を押す。
2. 右下の `デッキ` を押す。
3. デッキ内に追加カード、採用数、所持数、不足数が表示されることを見る。
4. 同じカードを4枚まで増やし、5枚目を追加できないことを見る。
5. `－` で元の枚数へ戻す。

正常なら、デッキに入れても所持数不足で追加自体は止まらず、不足数だけが表示されます。確認後はテスト用の採用を元へ戻します。

## 6. クラウド同期と未保存表示

1. 同期済み端末で `クラウド同期` を押す。
2. 同期コード、クラウド最終更新、この端末の最終同期、revision、過去の状態が確認できることを見る。
3. ダイアログを閉じ、デッキのカード枚数を1枚だけ変える。
4. `クラウド同期` ボタンに小さな未保存ドットが出ることを見る。
5. 同じカード枚数を元に戻す。

正常なら、元の同期基準と一致した時点で未保存ドットが消えます。別端末が更新している可能性は、通信前には表示しません。

## 7. 未保存変更がある状態での読み込み

1. 同期済み端末で、デッキ・候補・所持のいずれかを1つ変更する。
2. `クラウド同期` を開き、`クラウドから読み込み` を押す。

正常なら、ローカルの未保存変更がクラウド読み込みで置き換わる旨の警告が先に出ます。続行しなければ、端末データは変わりません。

## 8. スマホ表示

1. スマホで本番を開く。
2. `その他` の子分類、カード種類、候補、所持操作を順に使う。
3. `デッキ` と `クラウド同期` を開く。
4. 画面を左右へ動かして、不要な横スクロールが出ないことを見る。

正常なら、カードは画面幅に応じて1～2列で表示され、ボタン文字が切れず、ダイアログ・デッキ・ボタンが重なりません。

## 9. 確認後

テスト用に変更した候補、所持数、デッキ、同期状態は必要に応じて元へ戻します。意図しないクラウド保存や履歴復元は、確認目的だけでは実行しません。
